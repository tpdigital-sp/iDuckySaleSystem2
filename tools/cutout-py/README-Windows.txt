โปรแกรม cutout-py สำหรับเครื่อง Windows (พนักงานกราฟฟิก)
==========================================================

ใช้ทำอะไร
- ปุ่ม "🔁 ทำ .ai เลเยอร์ใหม่ด้วย Illustrator (เครื่องนี้)" ในหน้าออเดอร์หลังบ้าน
- จอออกแบบบนเว็บ (ปฏิทิน / โปสการ์ด / การ์ด) ทำไฟล์ .ai แยกเลเยอร์ + .pdf แนบออเดอร์ให้เอง
- หลังบ้าน /admin/diecut แท็บ "ตัดพื้นหลัง AI"
ทั้งหมดนี้ต้องเปิดโปรแกรมนี้ค้างไว้ "บนเครื่องที่มี Adobe Illustrator"


ติดตั้งครั้งแรก (ทำครั้งเดียว)
------------------------------
1) Python 3.12 — ไม่ต้องติดตั้งเอง: start.bat โหลด+ติดตั้งให้เอง (27 MB · ไม่ต้องใช้สิทธิ์แอดมิน)
   (เครื่องที่มี Python 3.13/3.14 อยู่แล้วก็ไม่เป็นไร ติดตั้ง 3.12 คู่กันได้)

2) แตกไฟล์ zip นี้ไว้ที่โฟลเดอร์ง่าย ๆ เช่น  C:\iDucky\cutout-py
   (แนะนำชื่อโฟลเดอร์ภาษาอังกฤษ ไม่มีเว้นวรรค)

3) เปิด Adobe Illustrator ด้วยมือ 1 ครั้ง ให้โหลดจนเสร็จ (ครั้งแรกหลังติดตั้งต้องล็อกอิน Adobe)

4) ดับเบิลคลิก  start.bat
   - ครั้งแรกจะติดตั้งไลบรารี 5–15 นาที (ต้องต่อเน็ต)
   - เสร็จแล้วโปรแกรมจะ "เปิดเองเบื้องหลัง" (ไม่มีหน้าต่างค้าง) และขึ้น
     "READY  http://localhost:8777   Illustrator found: True"  → ปิดหน้าต่างดำได้เลย
   - ครั้งแรกที่ใช้ตัดพื้นหลัง AI จะโหลดโมเดลอีก ~1 GB (เบื้องหลัง)
   - ถ้า Windows ขึ้น "Windows protected your PC" → กด More info → Run anyway


5) ⚠️ สำคัญ — อนุญาตให้เว็บคุยกับโปรแกรมในเครื่อง (ทำครั้งเดียวต่อเบราว์เซอร์)
   เปิด iduckystore.com ใน Chrome → กดไอคอนหน้าช่องที่อยู่เว็บ → การตั้งค่าเว็บไซต์ (Site settings)
   → "Local network access" (บางรุ่นชื่อ "Apps on device") → อนุญาต (Allow) → กด Ctrl+F5
   หรือพิมพ์ในช่องที่อยู่  chrome://settings/content/localNetworkAccess  → ช่อง Allowed เพิ่ม https://iduckystore.com
   ไม่ทำข้อนี้ = โปรแกรมเปิดอยู่ แต่เว็บต่อไม่ได้ → .ai ไม่แยกเลเยอร์ (ป้ายในจอออกแบบขึ้น 🔒 เบราว์เซอร์บล็อก .ai)
   เสร็จแล้วป้ายบนแถบบนของจอออกแบบต้องขึ้น  ● .ai พร้อม


ใช้งานทุกวัน — ไม่ต้องทำอะไร (เปิดเองอัตโนมัติ)
------------------------------------------------
- เปิดเครื่อง/ล็อกอิน Windows → โปรแกรมเปิดเองเบื้องหลัง
- ถ้าโปรแกรมปิดไป: กด "✓ ใช้แบบนี้" / "💾 บันทึกกลับเข้า OD-…" ในจอออกแบบ → เว็บสั่งเปิดให้เอง
  กด 🔁 ทำ .ai ใหม่ แล้วโปรแกรมปิดอยู่ → มีปุ่ม "▶ เปิดโปรแกรม" ขึ้นในจอ กด 1 ครั้ง ระบบทำไฟล์ต่อให้เอง
- ครั้งแรกที่เว็บสั่งเปิด Chrome/Edge จะถาม "เปิด iDucky cutout-py ไหม"
  → ติ๊ก "อนุญาตเสมอ / Always allow" แล้วกด "เปิด / Open" (ครั้งต่อไปไม่ถามอีก)
- เปิด Illustrator ไว้ด้วยก็ได้ (ไม่เปิด โปรแกรมจะเปิดให้เอง แต่ครั้งแรกช้า)
- ย้ายโฟลเดอร์โปรแกรมไปที่อื่น = ดับเบิลคลิก start.bat ใหม่ 1 ครั้ง (ลงทะเบียนที่อยู่ใหม่)


เช็คว่าใช้ได้ไหม
----------------
เปิด Chrome ไปที่  http://localhost:8777/calendar-ai
- ขึ้น  {"ok": true, "illustrator": true}   = พร้อมใช้ ✅
- ขึ้น  "illustrator": false                = หา Illustrator ไม่เจอ → ทำข้อ 3 อีกครั้ง / ซ่อม-ติดตั้ง Illustrator ใหม่
- เปิดไม่ได้เลย                            = โปรแกรมไม่ได้เปิด → ดับเบิลคลิก start.bat

ถ้า Chrome/Edge ถามว่า "iduckystore.com ต้องการเข้าถึงอุปกรณ์ในเครือข่ายเฉพาะที่ (local network)"
→ กด "อนุญาต / Allow" (เว็บต้องคุยกับโปรแกรมนี้ในเครื่อง)


ปัญหาที่เจอบ่อย
---------------
- "Python 3.12 (or 3.11) not found and automatic install failed" → เช็คเน็ต แล้วเปิด start.bat ใหม่
   ยังไม่ได้: ติดตั้งเองจาก https://www.python.org/downloads/release/python-31210/ ("Windows installer (64-bit)")
   หน้าแรกของตัวติดตั้งติ๊ก ✅ "Add python.exe to PATH" ก่อนกด Install Now (ห้ามใช้ 3.13/3.14 — ไลบรารีไม่รองรับ)
- "library install failed" → เช็คเน็ต แล้วดับเบิลคลิก start.bat อีกครั้ง
   ยังไม่หาย: ลบโฟลเดอร์ .venv ในโฟลเดอร์นี้ทิ้ง แล้วเปิด start.bat ใหม่ (ติดตั้งใหม่ทั้งหมด)
- กด 🔁 แล้วขึ้น "เปิด Adobe Illustrator ผ่าน COM ไม่ได้" → เปิด Illustrator ด้วยมือให้โหลดเสร็จ แล้วกดใหม่
- กด 🔁 แล้วค้างนาน → ดูหน้าต่าง Illustrator ว่ามีกล่องถาม/แจ้งเตือนค้างอยู่ไหม กดปิดแล้วลองใหม่
- โปรแกรมเปิดไม่ขึ้น/อยากเห็นข้อผิดพลาด → ดูไฟล์ cutout-py.log ในโฟลเดอร์นี้ หรือเปิดแบบมีหน้าต่าง:
   เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์  start.bat console
- อัปเดตโปรแกรม: ขอไฟล์ zip ชุดใหม่ แตกทับโฟลเดอร์เดิม (โฟลเดอร์ .venv เก็บไว้ได้) แล้วดับเบิลคลิก start.bat 1 ครั้ง
   (ถ้าโปรแกรมเก่ายังเปิดอยู่: รีสตาร์ตเครื่อง หรือปิด pythonw.exe ใน Task Manager ก่อน)
- เลิกเปิดเองอัตโนมัติ: เปิด PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์
   powershell -ExecutionPolicy Bypass -File setup-windows.ps1 -Remove
